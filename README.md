# AuthGateway

A full-stack user authentication application for secure registration and login.

## Technologies Used

- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Security:** bcrypt password hashing

## Features

- User registration
- User login
- Password hashing
- MongoDB integration
- Responsive user interface

## Installation

Clone the repository:

```bash
git clone <your-repository-url>
cd AuthGateway
```

Install dependencies and start the frontend and backend in their respective folders.
